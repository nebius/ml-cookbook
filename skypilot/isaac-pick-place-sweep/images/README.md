# README visuals

- `workflow.svg` describes this recipe's configuration, independent managed jobs, and per-case S3 publication. It is a workflow illustration, not a record of a cloud run.
- `sweep-grid.svg` maps the default values in `sweep.json` to the case IDs generated by `launch.py`. Cells are independent jobs.
- `rerun-sweep.webp` and `rerun-placed.webp` show measured poses from the [original Serverless Isaac Sim recipe](https://github.com/nebius/serverless-ai-cookbook/tree/354ad615ed8d4e07532125bb82add11fed5992f8/robotics/isaac-pick-place-sweep/images). They were captured on October 6, 2026, at 5.8 and 10.133 seconds of simulated time. They do not validate this SkyPilot adaptation.

The screenshots were copied from the original recipe and converted from PNG to lossless WebP. Their RGB pixels are unchanged. They show case names, task phases, and the simulation timeline; no account names, bucket names, job IDs, credentials, or personal details are visible.

The diagrams are editable SVG files with accessible titles and descriptions. They have no scripts, external resources, or embedded user data. Update the grid diagram if you change the documented default sweep.
