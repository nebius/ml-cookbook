# README visuals

- `workflow.svg` describes this recipe's configuration, independent managed jobs, and per-case S3 publication. It is a workflow illustration, not a record of a cloud run.
- `sweep-grid.svg` maps the default values in `sweep.json` to the case IDs generated by `launch.py`. Cells are independent jobs.
- `rerun-sweep.webp` and `rerun-placed.webp` show measured poses from the November 2, 2026 Nebius Compute sweep `20261102T211117Z-30aedde3`, managed jobs 6–9. See the [verification record](../validation/2026-11-02.json).

The recordings were downloaded from Object Storage, checked against the measured results, and replayed with this recipe's `visualize.py` and Rerun 0.38.1. Native Rerun screenshots were captured at 5.8 and 10.133333333 seconds, then converted from PNG to lossless WebP. Their RGB pixels are unchanged. They show case names, task phases, and the simulation timeline; no account names, bucket names, job IDs, credentials, or personal details are visible.

All four new trajectory payloads match the original Serverless default-grid recordings byte for byte. The fresh captures are also pixel-identical, so the image files themselves are unchanged; this note and the verification record document their new cloud provenance.

The diagrams are editable SVG files with accessible titles and descriptions. They have no scripts, external resources, or embedded user data. Update the grid diagram if you change the documented default sweep.
